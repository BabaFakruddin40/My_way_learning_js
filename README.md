# learn_java_script

A practice repository for learning JavaScript fundamentals and intermediate concepts.

## Structure

- `02basics/` - basic JavaScript exercises and examples
- `03_intermediate/` - intermediate concepts and object/method practice
- `Day_1/` - day-wise learning notes and code

## How to Run

Run any file with Node.js:

```bash
node path/to/file.js
```

Example:

```bash
node 03_intermediate/10object_method.js
```

## Prerequisites

- Node.js (recommended: latest LTS)

## Notes

This repository is for learning and experimentation.
